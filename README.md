# Bhasha Buddy — Android starter

This is the first starter project for the Bhasha Buddy app.

## Included in this first step
- Kotlin + Jetpack Compose Android project
- Welcome screen (name and age only; no login/account)
- Initial translator UI prototype
- Light / dark theme toggle prototype
- GitHub Actions workflow to build a debug APK

## Important
Translation, voice, persistent history, daily streak tracking, and AI support are UI placeholders at this stage. We will connect and implement them in later steps. The uploaded personal logo has not yet been added to this starter; we will add the exact logo asset once it is available in the project files.

## Build on GitHub
1. Create a GitHub repository named `BhashaBuddy`.
2. Upload all files and folders from this project to the repository root.
3. Open **Actions** and enable workflows if GitHub asks.
4. Select **Build Bhasha Buddy APK** → **Run workflow**.
5. When the run finishes, download the `BhashaBuddy-debug-apk` artifact.
